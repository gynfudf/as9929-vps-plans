## 9929 到底强在哪：和 4837、CN2 GIA 差在哪

联通的国际出口分两层。AS4837 是普通骨干，走的人多、单价低，晚高峰容易堵；AS9929 是联通单独维护的精品通道，签约单价更高、承载用户更少，拥堵程度明显低于 4837。业内把它叫作 CUII 或「联通精品网」，定位对标电信的 CN2 GIA。

回程路径是它最实用的部分。按公开的路由资料，电信用户回程走联通 9929 再接电信 163，联通用户直连 9929，移动用户则走 9929 转移动 CMI。第三方对丽萨这台精简版机器的路由记录也印证了类似结构：电信、联通方向落在 AS9929，移动方向走 CMIN2 / CMNET。结果是国内三网访问都不至于掉到普通线路的水平，联通宽带用户的体验尤其直接。

把三条高端线路放在一起看会更清楚。**下表是线路的普遍测评水平，不是丽萨主机的实测数据**，具体到某一家、某一个机房、某一个时段都会有出入：

关于 9929 适合谁，业内说法略有分歧：一种观点认为它「三网通吃」，电信和移动用户用起来也不差，只是最适合联通用户和预算敏感的人；另一种观点认为它对联通、移动用户更友好，联通宽带的体验甚至可能优于 CN2 GIA。两种说法可以并存，共同点是联通用户收益最大。

有一件事需要提前说清：9929 的价值主要体现在晚高峰和回程质量上，物理距离决定的延迟是消不掉的。美西方向 150–190ms 属于正常区间，指望它做到亚洲机的低延迟并不现实。

**9929 和 4837 怎么选？** 9929 质量更高、晚高峰更稳，价格也贵一档；4837 带宽更大、价格更低，适合对带宽敏感但对峰值延迟不那么在意的场景。丽萨两条线都做，同一预算下 4837 能买到更大的口子。

**双 ISP 住宅 IP 和普通原生 IP 差别大吗？** 对会检查 IP 类型的平台差别明显。住宅 IP 被识别为家宽，TikTok、Netflix、ChatGPT 这类服务通过率更高；普通原生 IP 属性是数据中心，部分平台会限制。只建站或做代理的话，原生 IP 就够，没必要付住宅 IP 的溢价。

**IP 被封了怎么办？** 非原生 IP 年付版可以付费更换，双 ISP 住宅版的 IP 相对干净、被封概率低。真遇到封锁，开工单咨询更换或加防御。

**要不要先月付实测？** 如果你对线路和 IP 都没把握，建议先月付或季付。年付便宜是真的，但 9929 的体验和你本地网络强相关，先花小钱验证，比一次性付一年再后悔划算。
